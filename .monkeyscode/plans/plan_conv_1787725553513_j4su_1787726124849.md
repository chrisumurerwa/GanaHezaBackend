## The new architecture

```
.env                              ← EXPO_PUBLIC_API_URL (no hardcode)
services/network.js               ← Network layer (URL, token, fetch, timeout, errors)
services/api.js                   ← Endpoint wrappers (imports from network.js)
contexts/                         ← Use api.js functions
screens/                          ← Use contexts + api.js
```

## ⚠️ Important — you must restart Metro

Since `EXPO_PUBLIC_*` env vars are inlined at **bundle time**, hot reload won't pick them up. Run:

```bash
cd Frontend
npx expo start -c
```

The `-c` flag clears the cache so Metro reads the new `.env` file. After that, the app will use `http://10.0.2.2:3000` from the environment variable — no more hardcoded URLs in source code.
