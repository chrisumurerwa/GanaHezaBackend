## Phase 1: Backend — Password Reset & Change Endpoints

**File: `backend/routes/auth.js`** — Added 3 new endpoints:

| Endpoint | Purpose |
|---|---|
| `POST /api/auth/forgot-password` | Accepts `{ email }`, verifies email exists, generates a 15-minute reset JWT, returns `{ resetToken }` |
| `POST /api/auth/reset-password` | Accepts `{ resetToken, newPassword }`, validates the JWT, hashes and saves the new password |
| `POST /api/auth/change-password` | Requires auth (JWT), accepts `{ currentPassword, newPassword }`, verifies current password, updates to new one |

**File: `backend/server.js`** — Updated startup console to list the new endpoints.

## How to Test

1. **Forgot Password**: Open login → tap "Forgot password?" → enter admin email → copy the reset token from the alert → enter new password + confirm → password is reset → log in with new password.

2. **Change Password**: Log in to dashboard → tap "Password" button (key icon) → enter current password + new password + confirm → password changed.

3. **Language Toggle**: On login page, tap EN/RW button → all text switches between English and Kinyarwanda.

> **Note**: The forgot-password reset token is returned directly in the API response (no email service yet). For production, this should be replaced with email-based reset. The token expires in 15 minutes.
